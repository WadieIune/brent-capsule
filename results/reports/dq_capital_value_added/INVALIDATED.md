# Retirado

No usar `summary.json` ni las cifras derivadas como resultado de capital o del
framework DQ. La estimación de «error de capital evitado» dependía de supuestos
no validados (cartera equiponderada, notional normalizado, prevalencia uniforme,
ventanas solapadas y detección equivalente a corrección perfecta) y FPR no
emparejada. El usuario retira esta línea del paper. Se conserva el archivo solo
como rastro de auditoría; no se publica ni se usa para decisiones.

La evaluación vigente está centrada en rendimientos y métricas DQ. Capital queda
fuera salvo que exista una cartera/posiciones y metodología explícitas aprobadas.
